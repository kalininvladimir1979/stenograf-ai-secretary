# Материалы для ручного прогона

Эти материалы не загружаются в базу и не создают встреч автоматически. Они нужны для проверки рабочего сценария после регистрации реального пользователя и создания организации.

1. Создайте организацию и отдел в приложении.
2. Создайте встречу с шаблоном «Рабочая встреча».
3. Для текстового сценария вставьте содержимое `meeting-notes-ru.md`.
4. Для сценария аудио загрузите `meeting-audio-en.wav`. Это синтетическая англоязычная запись той же логики встречи: решение, два поручения, риск и неизвестная информация. Она создана только для технического прогона Whisper, не является реальной записью.
5. Сверьте результат с разделом «Что должно получиться после анализа» в текстовом файле. Неуказанные в материале ответственные и сроки должны остаться пустыми и быть отмечены как требующие уточнения.

Для анализа текста и расшифровки аудио в админ-панели должен быть настроен действующий OpenAI API-ключ.
