# Демо-встречи и календарь

Владелец входит в Dev-консоль рабочим аккаунтом и открывает «Безопасность → Демо-режим».

Под «Использовать ключ платформы» находится «Количество встреч в демо-режиме». Значение 0 (по умолчанию) означает отсутствие ограничения. Положительное число ограничивает одновременно сохранённые добавленные встречи одного демо-браузера, совместно для его отделов. Учебные примеры не учитываются. Удаление освобождает место; изменение, распознавание дорожек, иллюстрации и повторный анализ существующей встречи не занимают новые места. Настройка проверяется на сервере при создании заметок, импорте ссылки, загрузке файла и создании встречи облачной папки. Повторная неизменённая ссылка не создаёт дополнительную встречу.

Старый demo_ai_limit и накопленный DemoSpace.used больше не блокируют AI-этапы. Это устраняет ошибку, когда лимит расходовался несколько раз на одну запись. Идентификаторы AI-операций по-прежнему обеспечивают идемпотентность. Ограничение иллюстраций на отчёт остаётся отдельной настройкой. Повторная обработка не расходует место, но может выполнять платные запросы к провайдеру.

Под пунктом «Календарь» находятся варианты «Месяц», «Неделя», «День», «Список». Выбор сразу сохраняется на сервере. Начальное значение — «Месяц». Изменение этой настройки применяет новую схему демо-календаря; после этого посетитель может переключать свой вид, который сохраняется в его браузере до следующего изменения схемы по умолчанию.

Учебный код 1234 не позволяет менять эти настройки. Рабочие организации не ограничиваются демо-лимитом. Старые встречи со сбоем материалов можно продолжить кнопкой «Повторить обработку»: сервер возобновляет сохранённую задачу материалов, а не требует заново загружать уже скачанный файл.

Проверки: cloud.test.ts (конкурентный лимит, учебные примеры, удаление, безлимит, повтор материалов), demo-meeting-settings-http.mjs (HTTP-лимит и доступ владельца, сохранение календаря), http-isolation.mjs. Тесты выполняются только в локальной базе, с удалением собственных фикстур и восстановлением конфигурации.
